# 5. Listas en Python

Una lista es como una fila de cajas numeradas donde puedes guardar valores en orden y luego cambiarlos. Es el contenedor más usado en Python.

---

## 5.1 Creación y acceso

```python
tareas = ["Lavar", "Comprar", "Estudiar"]  # Lista con 3 strings
print(tareas[0])   # Primer elemento (índice 0)
print(tareas[-1])  # Último elemento
```

Si usas un índice que no existe (ej: 10 en una lista de 3) obtendrás `IndexError`.

---

## 5.2 Modificación (listas son mutables)

```python
tareas.append("Dormir")         # Añade al final
tareas.insert(1, "Pasear")       # Inserta en posición 1
tareas[0] = "Lavar platos"       # Reemplaza valor existente
```

---

## 5.3 Eliminación

```python
tareas.remove("Comprar")  # Elimina por valor (solo primera coincidencia)
ultima = tareas.pop()      # Saca y devuelve el último
primera = tareas.pop(0)    # Saca el primero
# del tareas[1]            # Otra forma de eliminar por índice
```

`remove` lanza `ValueError` si el valor no está.

---

## 5.4 Iteración

```python
for t in tareas:
    print("Tarea:", t)
```

También puedes usar índices:

```python
for i in range(len(tareas)):
    print(i, tareas[i])
```

---

## 5.5 Comprensiones de listas (forma compacta)

Construyen listas nuevas a partir de un bucle interno.

```python
cuadrados = [n*n for n in range(1, 6)]           # [1,4,9,16,25]
pares = [n for n in range(20) if n % 2 == 0]     # Solo pares
```

Equivalen a escribir un `for` y hacer `append`.

---

## 5.6 Copias vs referencias

```python
original = [1,2,3]
copia = original[:]      # Copia superficial
otra = original          # MISMA lista (referencia)
original[0] = 99
print(copia)  # [1,2,3]
print(otra)   # [99,2,3]
```

---

## 5.7 Métodos principales (explicados)

| Método         | Para qué sirve                         | Ejemplo           | Resultado       |
| -------------- | -------------------------------------- | ----------------- | --------------- |
| `append(x)`    | Añadir al final                        | `l.append(4)`     | `[1,2,3,4]`     |
| `extend(iter)` | Añadir varios                          | `l.extend([5,6])` | `[1,2,3,4,5,6]` |
| `insert(i,x)`  | Insertar en índice                     | `l.insert(1, 99)` | Desplaza resto  |
| `remove(x)`    | Quitar primera aparición               | `l.remove(2)`     | Sin primer 2    |
| `pop(i?)`      | Quitar y devolver (último por defecto) | `l.pop()`         | último valor    |
| `clear()`      | Vaciar lista                           | `l.clear()`       | `[]`            |
| `index(x)`     | Índice de primera aparición            | `l.index(3)`      | número          |
| `count(x)`     | Cuántas veces aparece                  | `l.count(2)`      | cantidad        |
| `sort()`       | Ordenar en sitio                       | `l.sort()`        | lista ordenada  |
| `reverse()`    | Invertir en sitio                      | `l.reverse()`     | invertida       |
| `copy()`       | Copia superficial                      | `l.copy()`        | nueva lista     |

Notas:

- Para ordenar sin tocar la original: `nueva = sorted(lista)`.
- `sort(key=..., reverse=True)` permite personalizar.

---

## 5.8 Ordenación con clave

```python
personas = ["ana", "Luis", "mario"]
personas.sort(key=str.lower)  # Ordena ignorando mayúsculas
```

---

## 5.9 Desempaquetado rápido

```python
primero, segundo, *resto = [10,20,30,40]
print(primero, segundo, resto)  # 10 20 [30,40]
```

---

## 5.10 Errores comunes

- `IndexError`: índice fuera de rango.
- Modificar la lista mientras iteras sobre ella (puede saltar elementos). Mejor crear una nueva.
- Asumir que `sort()` devuelve lista (devuelve `None`).

---

## 5.11 Patrones útiles

Eliminar duplicados manteniendo orden:

```python
visto = set()
resultado = []
for x in [1,2,2,3,1]:
    if x not in visto:
        visto.add(x)
        resultado.append(x)
print(resultado)  # [1,2,3]
```

Filtrar y transformar a la vez:

```python
nums = [1,2,3,4,5]
cuadrados_pares = [n*n for n in nums if n % 2 == 0]
```

## 5.13 Resumen súper simple

- Lista = colección ordenada y mutable.
- Puedes añadir, quitar, cambiar.
- Métodos como `append`, `remove`, `sort` son tus básicos.
- Comprensiones hacen el código más corto y claro.

Dominar listas te facilita casi todos los problemas iniciales en Python.
