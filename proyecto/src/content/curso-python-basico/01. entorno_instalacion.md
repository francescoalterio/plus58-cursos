# 1. Preparando el Entorno (Instalación)

Piensa en esto como montar tu taller antes de construir cosas. Necesitas: (a) el lenguaje (Python) y (b) un editor cómodo (VS Code).

---

## 1.1 Instalar Python (el motor)

1. Ir a https://www.python.org/downloads/
2. Descargar la versión estable (no prerelease).
3. En Windows marcar la casilla: "Add Python to PATH" (muy importante para usar `python` en la terminal).
4. Aceptar instalación por defecto.
5. Verificar en PowerShell:

```powershell
python --version
```

Si ves algo como `Python 3.x.x` todo bien. Si no, cierra y reabre la terminal.

### ¿Qué es PATH?

Es una lista de rutas donde el sistema busca programas. Al marcar la casilla evitas configuraciones manuales.

---

## 1.2 Instalar VS Code (tu editor)

1. Ir a https://code.visualstudio.com
2. Descargar e instalar.
3. Abrir VS Code.
4. Icono de Extensiones (bloques): buscar `Python` (Microsoft) e instalar.
5. (Opcionales útiles): `Pylance` (intellisense), `autopep8` o `Black` (formato), `isort` (organizar imports).

---

## 1.3 Crear tu primer script

Archivo `hola.py`:

```python
print("Hola Python")
```

Ejecutar:

```powershell
python hola.py
```

Verás: `Hola Python`.

---

## 1.4 REPL interactivo (probar rápido)

Escribe en terminal:

```powershell
python
```

Aparecerá `>>>`. Ahora puedes tipear:

```python
2 + 5
print("Hola")
```

Para salir: `exit()` o Ctrl+Z y Enter en Windows.

---

## 1.5 Estructura básica de un proyecto

```
mi_proyecto/
  README.md
  src/
    main.py
```

- `README.md`: anota propósito y cómo ejecutar.
- `src/`: tu código.

---

## 1.6 Buenas prácticas iniciales

- Nombres de carpetas y archivos en minúsculas y sin espacios (usa `_`).
- Un archivo por tema al inicio evita confusión.
- Guarda seguido (Ctrl+S) y ejecuta con frecuencia para detectar errores temprano.

---

## 1.7 Solución de problemas comunes

| Problema                | Causa probable        | Solución                                           |
| ----------------------- | --------------------- | -------------------------------------------------- |
| `python` no se reconoce | No se añadió a PATH   | Reinstalar marcando casilla o usar `py` en Windows |
| Versiones mezcladas     | Varias instalaciones  | `where python` para ver rutas                      |
| No corre script         | Estás en otra carpeta | `dir` (Windows) para listar y confirmar ubicación  |

---

## 1.8 Extensiones recomendadas

| Extensión          | Para qué                       |
| ------------------ | ------------------------------ |
| Python (Microsoft) | Depuración, ejecución, linting |
| Pylance            | Mejor autocompletado           |
| Black o autopep8   | Formato consistente            |
| isort              | Ordenar imports                |
| Error Lens         | Ver errores en línea           |

## 1.10 Resumen súper simple

1. Instala Python (marca PATH).
2. Instala VS Code + extensión Python.
3. Crea y ejecuta `hola.py`.

5. Mantén orden: carpetas claras.
