# 8. Strings y Métodos

Un string es texto: una secuencia de caracteres. Es inmutable (no puedes cambiar una letra directamente, creas uno nuevo).

---

## 8.1 Crear y ver

```python
nombre = "Ana"
frase = "Hola Mundo"
```

Longitud:

```python
print(len(frase))  # 10 (contando espacio)
```

---

## 8.2 Indexación y slicing

```python
texto = "Python"
print(texto[0])     # P
print(texto[-1])    # n
print(texto[1:4])   # yth
print(texto[::-1])  # nohtyP (invertido)
```

---

## 8.3 Principales métodos (explicados de forma simple)

| Método            | Qué hace                  | Ejemplo                   | Resultado      |
| ----------------- | ------------------------- | ------------------------- | -------------- |
| `upper()`         | Mayúsculas                | `"hola".upper()`          | `"HOLA"`       |
| `lower()`         | Minúsculas                | `"HoLa".lower()`          | `"hola"`       |
| `capitalize()`    | Primera en mayúscula      | `"python".capitalize()`   | `"Python"`     |
| `title()`         | Cada palabra en mayúscula | `"hola mundo".title()`    | `"Hola Mundo"` |
| `strip()`         | Quita espacios extremos   | `"  hola \n".strip()`     | `"hola"`       |
| `replace(a,b)`    | Cambia texto              | `"hola".replace("h","H")` | `"Hola"`       |
| `split(sep)`      | Divide en lista           | `"a,b".split(",")`        | `["a","b"]`    |
| `find(sub)`       | Posición o -1             | `"banana".find("na")`     | `2`            |
| `count(sub)`      | Veces que aparece         | `"banana".count("a")`     | `3`            |
| `startswith(pre)` | ¿Comienza así?            | `"hola".startswith("ho")` | False          |
| `endswith(suf)`   | ¿Termina así?             | `"hola".endswith("la")`   | True           |
| `join(iter)`      | Une con separador         | `",".join(["a","b"])`     | `"a,b"`        |
| `isdigit()`       | Solo dígitos 0-9          | `"123".isdigit()`         | True           |
| `isalpha()`       | Solo letras               | `"Hola".isalpha()`        | True           |
| `isalnum()`       | Letras o números          | `"Hola1".isalnum()`       | True           |
| `isspace()`       | Solo espacios             | `"  \t".isspace()`        | True           |
| `zfill(n)`        | Rellenar con ceros        | `"42".zfill(5)`           | `"00042"`      |

Otros útiles: `isdecimal()`, `isnumeric()`, `islower()`, `isupper()`.

---

## 8.4 Formateo de cadenas (f-strings)

Forma recomendada por claridad.

```python
nombre = "Ana"
edad = 30
print(f"Me llamo {nombre} y tengo {edad} años")
```

También:

```python
valor = 3.14159
print(f"Pi ≈ {valor:.2f}")  # 2 decimales
```

---

## 8.5 Inmutabilidad (por qué importa)

No puedes hacer: `texto[0] = 'X'` (error). Debes crear uno nuevo:

```python
texto = "python"
texto = "P" + texto[1:]
print(texto)  # PythoN? (si quisieras modificar final igual)
```

---

## 8.6 Limpieza y normalización

Quitar espacios múltiples:

```python
raw = "Hola    mundo   Python"
normal = " ".join(raw.split())
print(normal)  # Hola mundo Python
```

Pasar a minúsculas y quitar adornos para comparar:

```python
usuario = "  Ana \n"
if usuario.strip().lower() == "ana":
    print("Coincide")
```

---

## 8.7 Conteo de vocales (ejemplo práctico)

```python
texto = "Programacion"
vocales = 0
for c in texto.lower():
    if c in "aeiou":
        vocales += 1
print(vocales)
```

---

## 8.8 Errores comunes

- Usar un índice fuera de rango => `IndexError`.
- Olvidar que `split()` sin argumento separa por cualquier espacio.
- Intentar modificar una letra directamente.
- Confundir `find()` (devuelve -1) con lanzar error (no lo hace).

## 8.10 Resumen súper simple

- String = texto inmutable.
- Métodos ayudan a limpiar, buscar y transformar.
- f-strings = la forma más clara de insertar valores.
- Slicing te permite extraer y reorganizar partes.

Con esto puedes procesar casi cualquier texto básico en tus programas.
