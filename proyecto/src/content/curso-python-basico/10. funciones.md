# 10. Funciones

Bloques reutilizables que reciben datos (parámetros) y pueden devolver resultados.

---

## 10.1 Definición básica

```python
def saludar(nombre):
    return f"Hola {nombre}"
print(saludar("Ana"))
```

`return` termina la función. Si omites `return` devuelve `None`.

---

## 10.2 Parámetros y argumentos

```python
def sumar(a, b):
    return a + b
resultado = sumar(2,3)
```

- Parámetro: el nombre dentro de la definición.
- Argumento: el valor que pasas al llamar.

---

## 10.3 Tipos de parámetros (orden lógico)

```python
def ejemplo(pos1, pos2, /, pos_kwd, *args, clave1, clave2=10, **kwargs):
    pass
```

Orden (si se usan todos):

1. Posicionales puros (antes de `/`).
2. Posicionales o por nombre.
3. `*args` (tupla de extras posicionales).
4. Parámetros solo clave (después de `*`).
5. Con valores por defecto.
6. `**kwargs` (diccionario de extras por nombre).

Simplificado frecuente:

```python
def f(a, b=0, *args, **kwargs):
    ...
```

---

## 10.4 Valores por defecto (cuidado con mutables)

```python
def agregar(elemento, lista=None):
    if lista is None:
        lista = []
    lista.append(elemento)
    return lista
```

Nunca uses directamente `lista=[]` como parámetro si planeas modificarlo (se reutiliza entre llamadas).

---

## 10.5 \*args y \*\*kwargs

```python
def mostrar(*args, **kwargs):
    print(args)     # tupla
    print(kwargs)   # dict

mostrar(1,2,3, x=10, y=20)
```

Útil para funciones flexibles.

---

## 10.6 Anotaciones de tipos (opcional pero recomendable)

```python
def area_rect(base: float, altura: float) -> float:
    return base * altura
```

Solo documentación para humanos y herramientas; Python no obliga.

---

## 10.7 Documentar con docstrings

```python
def sumar(a:int, b:int)->int:
    """Devuelve la suma de a y b.

    Args:
        a (int): primer número.
        b (int): segundo número.
    Returns:
        int: resultado de a + b.
    """
    return a + b
```

Acceso: `help(sumar)` o `sumar.__doc__`.

---

## 10.8 Funciones puras vs impuras

- Pura: mismo resultado con mismos argumentos, no cambia nada fuera.
- Impura: lee/modifica variables globales, archivos, imprime.
  Preferir puras para facilidad de pruebas.

---

## 10.9 Variables globales vs locales

```python
x = 10

def cambiar():
    global x
    x = 99
```

Evita abusar de `global`; pasa datos por parámetros y retornos.

---

## 10.10 Retornar múltiples valores

En realidad retorna una tupla.

```python
def dividir(a,b):
    return a//b, a%b
q, r = dividir(10,3)
```

---

## 10.11 Funciones anidadas y cierre (closure)

```python
def crear_sumador(n):
    def sumar(x):
        return x + n  # recuerda n
    return sumar

suma5 = crear_sumador(5)
print(suma5(10))  # 15
```

La función interna recuerda el valor de `n`.

---

## 10.12 Recursión (función que se llama a sí misma)

```python
def factorial(n):
    if n<=1:
        return 1
    return n * factorial(n-1)
```

Necesita caso base para no ser infinita. Recursión profunda puede dar RecursionError.

---

## 10.13 Lambda (funciones pequeñas anónimas)

```python
cuadrado = lambda x: x*x
print(cuadrado(4))
```

Usar solo para expresiones simples (filtro, orden, map):

```python
nums = [3,1,2]
ordenados = sorted(nums, key=lambda n: n)
```

---

## 10.14 Higher-order functions (reciben o devuelven funciones)

```python
def aplicar(f, x):
    return f(x)
print(aplicar(lambda n: n+1, 5))
```

---

## 10.15 Generadores (mención breve)

```python
def contar(n):
    for i in range(n):
        yield i
```

`yield` produce valores uno a uno (ahorra memoria).

---

## 10.16 Manejo de errores dentro de funciones

```python
def dividir_seguro(a,b):
    if b == 0:
        raise ValueError("b no puede ser 0")
    return a/b
```

Levantar (raise) da control claro al llamador.

---

## 10.18 Resumen súper simple

- Función = bloque reutilizable.
- Parámetros definen, argumentos llaman.
- Usa `None` como marcador y crea dentro la lista/dict mutable.
- `*args` agrupa posicionales extra, `**kwargs` los nombrados extra.
- Tipos y docstrings ayudan a entender.
- Recursión: llamarse hasta caso base.
- Generadores producen valores bajo demanda.
