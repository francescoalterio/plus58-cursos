# 11. Módulos e Imports

Un módulo es simplemente un archivo `.py` con código (funciones, variables, clases) que puedes reutilizar. Importar = traer herramientas de otro archivo para usarlas aquí.

---

## 11.1 ¿Para qué sirven?

- Separar temas.
- Reusar código sin copiar y pegar.
- Organizar proyectos grandes en piezas pequeñas.

---

## 11.2 Importar módulos estándar

Python trae una "caja de herramientas" grande por defecto (biblioteca estándar).

```python
import math
print(math.sqrt(16))  # 4.0
print(math.pi)        # 3.14159...
```

Importar varios:

```python
import math, random
print(random.randint(1, 6))
```

Formas comunes:

```python
import math              # math.sqrt(9)
import math as m         # m.sqrt(9)
from math import sqrt    # sqrt(9)
from math import pi, ceil
```

Evita `from math import *` (importa todo y ensucia nombres).

---

## 11.3 Tu propio módulo

Archivo `utilidades.py`:

```python
# utilidades.py

def es_par(n):
    return n % 2 == 0
```

Usarlo en `main.py`:

```python
import utilidades
print(utilidades.es_par(4))
```

---

## 11.4 El bloque especial `if __name__ == "__main__"`

Sirve para poner pruebas que solo se ejecutan si corres directamente ese archivo.

```python
# utilidades.py

def saludo():
    return "Hola"

if __name__ == "__main__":
    print("Pruebas rápidas:", saludo())
```

Si alguien hace `import utilidades`, el bloque no se ejecuta.

---

## 11.5 Paquetes

Un paquete es una carpeta con módulos y un archivo `__init__.py` (puede estar vacío).

```
mi_proyecto/
  main.py
  herramientas/
    __init__.py
    numeros.py
    cadenas.py
```

`numeros.py`:

```python
def doble(n):
    return n * 2
```

`cadenas.py`:

```python
def invertir(s):
    return s[::-1]
```

`herramientas/__init__.py`:

```python
from .numeros import doble
from .cadenas import invertir
```

Uso en `main.py`:

```python
from herramientas import doble, invertir
print(doble(5))
print(invertir("hola"))
```

---

## 11.6 Rutas donde Python busca módulos (`sys.path`)

Python busca en:

1. Carpeta del script que ejecutas.
2. Variables de entorno configuradas.
3. Carpeta de instalación y paquetes instalados.

Puedes ver la lista:

```python
import sys
print(sys.path)
```

No modifiques esta lista salvo que sepas lo que haces.

---

## 11.7 Módulos útiles frecuentes

| Módulo       | Para qué                 | Ejemplo                   |
| ------------ | ------------------------ | ------------------------- |
| `math`       | Matemática               | `math.sqrt(25)`           |
| `random`     | Aleatoriedad             | `random.choice(lista)`    |
| `datetime`   | Fechas y horas           | `datetime.datetime.now()` |
| `os`         | Rutas, archivos, entorno | `os.listdir()`            |
| `statistics` | Estadística básica       | `statistics.mean(datos)`  |

---

## 11.8 Errores comunes

- Nombrar tu archivo igual que un módulo estándar (`random.py`) y luego no poder importar el original.
- Usar `import *` y sobreescribir nombres sin querer.
- Olvidar crear `__init__.py` en un paquete (en versiones modernas a veces funciona, pero mejor incluirlo para claridad).

---

## 11.10 Resumen súper simple

- Módulo = archivo reutilizable.
- Paquete = carpeta de módulos.
- `import` trae funciones de otros lados.
- `__name__ == "__main__"` para pruebas internas.

Con esto puedes dividir tu programa en piezas limpias y fáciles de mantener.
