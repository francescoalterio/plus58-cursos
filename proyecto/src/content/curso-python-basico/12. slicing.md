# 9. Slicing

Slicing es cortar partes (sub-secuencias) de cadenas, listas, tuplas. Sintaxis: `secuencia[inicio:fin:paso]`.

---

## 9.1 Índices básicos

Para una lista:

```python
nums = [0,1,2,3,4,5,6,7]
#        0 1 2 3 4 5 6 7
#       -8-7-6-5-4-3-2-1 (índices negativos)
```

---

## 9.2 Cortes simples

```python
nums[2:5]    # [2,3,4] (fin NO se incluye)
nums[:4]     # [0,1,2,3]
nums[4:]     # [4,5,6,7]
nums[:]      # copia superficial
```

---

## 9.3 Paso (step)

```python
nums[::2]    # [0,2,4,6]
nums[1::2]  # [1,3,5,7]
```

---

## 9.4 Invertir

```python
nums[::-1]  # [7,6,5,4,3,2,1,0]
texto = "hola"
texto[::-1]  # 'aloh'
```

---

## 9.5 Rango fuera de límites

No da error: se ajusta.

```python
nums[-100:100]  # lista completa
```

---

## 9.6 Paso negativo

```python
nums[5:1:-1]  # [5,4,3,2]
nums[5::-1]   # [5,4,3,2,1,0]
nums[:2:-1]   # [7,6,5,4,3]
```

Regla mental: con paso negativo el corte avanza hacia la izquierda; el índice fin sigue SIN incluirse.

---

## 9.7 Omisiones inteligentes

- Si omites inicio con paso positivo: empieza al principio.
- Si omites fin con paso positivo: llega al final.
- Con paso negativo y omites inicio: empieza al final.
- Con paso negativo y omites fin: llega al inicio.

---

## 9.8 Copia vs referencia

`lista[:]` crea una copia superficial; objetos internos siguen compartidos.

```python
matriz = [[1,2],[3,4]]
clon = matriz[:]
clon[0].append(99)
print(matriz[0])  # [1,2,99]
```

---

## 9.9 Reemplazo por slicing

```python
nums[2:5] = [20,30]  # acorta
nums[0:0] = [-1,-2]  # inserta al inicio
nums[3:3] = [999]    # inserta en medio
```

La longitud puede cambiar.

---

## 9.10 Eliminar por slicing

```python
del nums[1:4]
```

---

## 9.11 Slicing en strings (inmutables)

Devuelve nuevo string (original intacto):

```python
s = "programa"
sub = s[0:4]  # 'prog'
```

---

## 9.12 Errores comunes

- Confundir que el fin se incluye (NO se incluye).
- Olvidar que invertir es `[::-1]` (no `[:: -1]` con espacio).
- Creer que `lista[:]` copia profundo (no lo hace).

2. Invertir una cadena y comprobar si es palíndromo.
3. Extraer caracteres en posiciones pares de un string.
4. Insertar una sublista al inicio usando slicing asignación.

---

## 9.14 Resumen súper simple

- Forma: inicio:fin:paso (fin excluido).
- Índices negativos cuentan desde el final.
- `[::-1]` invierte.
- `[:]` copia superficial.
- Se puede usar para reemplazar, insertar y borrar trozos.
