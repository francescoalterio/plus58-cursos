# 3. Variables y Tipos de Datos

Aprender variables y tipos es como conocer las piezas básicas de construcción. Con esto podrás entender todo lo que sigue en Python.

---

## 3.1 ¿Qué es una variable?

Es un nombre que apunta a un valor. El nombre es la etiqueta, el valor es el contenido.

```python
edad = 25
nombre = "Ana"
```

Puedes cambiar a qué valor apunta:

```python
edad = 25
edad = 26  # ahora apunta a 26
```

---

## 3.2 Reglas de nombres y estilo

- Puede contener letras, números y `_`, pero no iniciar con número.
- Diferencia mayúsculas/minúsculas: `dato` ≠ `Dato`.
- Estilo recomendado: `snake_case` -> `total_pagar`.
- Constantes: MAYÚSCULAS: `PI = 3.1416`.
- Nombres claros: `contador`, `precio_total`.

---

## 3.3 Tipado dinámico

El tipo va con el valor, no con el nombre.

```python
x = 10      # int
x = "hola"  # ahora str
```

---

## 3.4 Tipos básicos frecuentes

| Tipo     | Ejemplo    | Descripción breve      |
| -------- | ---------- | ---------------------- |
| int      | 7          | Entero (sin decimales) |
| float    | 3.14       | Número con decimales   |
| bool     | True/False | Lógico                 |
| str      | "Hola"     | Texto                  |
| NoneType | None       | Sin valor / vacío      |

---

## 3.5 Estructuras de datos clave

| Tipo  | Sintaxis | Mutabilidad | Uso común                                  |
| ----- | -------- | ----------- | ------------------------------------------ |
| list  | [1,2,3]  | Mutable     | Colección ordenada que cambia              |
| tuple | (1,2,3)  | Inmutable   | Grupo fijo de valores                      |
| dict  | {"a":1}  | Mutable     | Pares clave:valor, acceso rápido           |
| set   | {1,2,3}  | Mutable     | Elementos únicos, operaciones de conjuntos |
| range | range(5) | Inmutable   | Secuencia para bucles                      |

---

## 3.6 Mutables vs inmutables

- Inmutables: int, float, str, tuple, bool, None. No se pueden alterar internamente.
- Mutables: list, dict, set. Se modifican en sitio.

```python
texto = "hola"
# texto[0] = 'H'  # Error
nums = [1,2,3]
nums[0] = 99  # OK
```

---

## 3.7 Conversión (casting)

```python
n = int("40")    # 40
f = float("4.5") # 4.5
s = str(100)      # "100"
```

Si falla: ValueError.

---

## 3.8 Entrada de usuario

`input()` siempre devuelve string.

```python
edad = int(input("Edad: "))
```

---

## 3.9 Desempaquetado y asignación múltiple

```python
a, b = 1, 2
b, a = a, b
primero, *medio, ultimo = [1,2,3,4,5]
```

---

## 3.10 Truthiness (qué es falso)

En un `if`, se considera FALSO: `0`, `0.0`, `""`, `[]`, `()`, `{}`, `set()`, `range(0)`, `False`, `None`. Todo lo demás es True.

```python
if []:
    print("no")
if [0]:
    print("sí")  # lista no vacía
```

---

## 3.11 Copias superficiales vs referencias

```python
lista = [1,2]
alias = lista
lista.append(3)
print(alias)  # [1,2,3]
# Copia superficial
copia = lista[:]
```

---

## 3.12 Conversión entre colecciones

```python
lista = [1,2,2,3]
sin_dups = list(set(lista))  # pierde orden original
texto = ",".join(["a","b"])  # "a,b"
```

---

## 3.13 Elegir el tipo correcto (guía rápida)

| Necesitas                      | Escoge |
| ------------------------------ | ------ |
| Secuencia ordenada modificable | list   |
| Grupo fijo                     | tuple  |
| Acceso por clave               | dict   |
| Elementos únicos               | set    |
| Rango de números               | range  |
| Texto                          | str    |
| Ausencia de valor              | None   |

---

## 3.14 Errores comunes

- NameError: usar variable antes de asignar.
- Olvidar convertir `input()`.
- Creer que copiar con `=` crea lista nueva (solo referencia).
- Cambiar un inmutable esperando efecto (ej: carácter de un string).

---

## 3.15 Buenas prácticas

- Nombres semánticos cortos.
- Constantes en mayúsculas.
- Evitar mezclar tipos en la misma lista sin necesidad.
- Usar f-strings para componer texto: `f"Hola {nombre}"`.

## 3.17 Resumen súper simple

Variable = nombre -> valor.
Tipos básicos: int, float, str, bool, None.
Estructuras: list (mutable), tuple (fija), dict (clave:valor), set (únicos).
Convierte tipos cuando uses input.
Elige el tipo según tu necesidad. Listo para operadores.
