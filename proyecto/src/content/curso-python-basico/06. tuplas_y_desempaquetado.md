# 6. Tuplas y Desempaquetado

Una tupla es como una lista que NO se puede cambiar (inmutable) y se escribe con paréntesis. El desempaquetado es repartir sus valores en variables de forma rápida.

---

## 6.1 Tuplas: qué son y por qué usarlas

```python
punto = (10, 20, 5)
print(punto[0])  # 10
```

Ventajas:

- Protección: no se modifican por accidente.
- Eficientes en memoria.
- Se pueden usar como claves en diccionarios (las listas no).

Usos típicos: coordenadas, constantes, retornos múltiples de funciones.

---

## 6.2 Desempaquetado básico

```python
x, y, z = punto
print(x, y, z)
```

El número de variables debe coincidir con el número de elementos.

Error común:

```python
a, b = (1,2,3)  # ValueError (sobran elementos)
```

---

## 6.3 Desempaquetado extendido con `*`

Captura “el resto” en una lista.

```python
numeros = [1,2,3,4,5,6]
primero, *centro, ultimo = numeros
print(primero, centro, ultimo)  # 1 [2,3,4,5] 6
```

Más ejemplos:

```python
primero, segundo, *resto = numeros
*inicio, penultimo, ultimo = numeros
```

---

## 6.4 Ignorar valores con `_`

Convención para valores que no interesan.

```python
a, _, c = (1,2,3)
```

Con extendido:

```python
primera, *_, ultima = [10,20,30,40]
```

---

## 6.5 Desempaquetado en bucles

```python
productos = [("Pan",1.5),("Leche",1.2)]
for nombre, precio in productos:
    print(nombre, precio)
```

Más legible que usar índices.

---

## 6.6 Intercambio rápido de variables

```python
a, b = 10, 20
a, b = b, a
print(a, b)  # 20 10
```

Evita variable temporal.

---

## 6.7 Retorno múltiple en funciones

Python devuelve tuplas (implícitas) fácilmente.

```python
def dividir(a,b):
    return a//b, a%b
q, r = dividir(10,3)
print(q, r)
```

---

## 6.8 Usos prácticos

Enumerar pares clave-valor:

```python
config = {"host":"localhost", "port":8080}
for clave, valor in config.items():
    print(clave, valor)
```

Procesar listas de tuplas:

```python
puntos = [(1,2),(3,4),(5,6)]
suma_x = sum(x for x, _ in puntos)
```

---

## 6.9 Errores comunes

- Desajuste de cantidades al desempaquetar.
- Olvidar que una coma crea tupla aunque no haya paréntesis: `t = 1,` (tupla de un elemento).
- Intentar modificar un elemento: `punto[0] = 99` (TypeError).

## 6.10 Mini ejercicios

1. Extraer primero y último de una lista grande usando `*` sin conocer su longitud.
2. Intercambiar tres variables `a->b`, `b->c`, `c->a` en una sola línea (pista: tupla rotada).
3. Recorrer un dict e imprimir `clave=valor` usando desempaquetado de `.items()`.

---

## 6.11 Resumen súper simple

- Tupla: lista inmutable.
- Desempaquetar: repartir elementos en variables.
- `*` reúne los “restantes”.
- `_` ignora valores.

Te ahorra código repetitivo y mejora legibilidad.
