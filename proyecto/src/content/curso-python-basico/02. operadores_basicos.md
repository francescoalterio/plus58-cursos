# 2. Operadores Básicos en Python

Los operadores son símbolos que le dicen a Python que haga una acción concreta (sumar, restar, comparar, unir condiciones, etc.). Entenderlos bien es como aprender a usar las herramientas básicas de una caja de herramientas. Si dominas esto, escribirás código claro y sin confusiones.

---

## 2.1 Operadores Aritméticos (cuentas con números)

Sirven para hacer operaciones matemáticas simples.

| Operador | Qué hace                              | Ejemplo  | Resultado |
| -------- | ------------------------------------- | -------- | --------- |
| `+`      | Suma                                  | `5 + 2`  | 7         |
| `-`      | Resta                                 | `5 - 2`  | 3         |
| `*`      | Multiplica                            | `5 * 2`  | 10        |
| `/`      | Divide (resultado decimal)            | `5 / 2`  | 2.5       |
| `//`     | División entera (corta los decimales) | `5 // 2` | 2         |
| `%`      | Resto de la división                  | `5 % 2`  | 1         |
| `**`     | Potencia                              | `5 ** 2` | 25        |

```python
a = 7
b = 3
print(a + b)  # 10
print(a - b)  # 4
print(a * b)  # 21
print(a / b)  # 2.333...
print(a // b) # 2
print(a % b)  # 1
print(a ** b) # 343 (7 * 7 * 7)
```

¿Cuándo usar `%`? Por ejemplo para saber si un número es par:

```python
n = 14
print(n % 2 == 0)  # True (sí es par)
```

## 2.2 Operadores de Comparación (hacen preguntas)

Comparan dos valores y devuelven True (verdadero) o False (falso).

| Operador | Significa      | Ejemplo   | Resultado |
| -------- | -------------- | --------- | --------- |
| `==`     | Es igual a     | `5 == 5`  | True      |
| `!=`     | Es distinto de | `5 != 3`  | True      |
| `<`      | Menor que      | `3 < 8`   | True      |
| `>`      | Mayor que      | `10 > 11` | False     |
| `<=`     | Menor o igual  | `5 <= 5`  | True      |
| `>=`     | Mayor o igual  | `6 >= 7`  | False     |

```python
saldo = 100
print(saldo > 50)    # True
print(saldo == 0)    # False
print(saldo != 100)  # False
```

---

## 2.3 Operadores Lógicos (combinan condiciones)

Permiten unir varias comparaciones para formar reglas más completas.

| Operador | Explicación breve                         | Ejemplo                | Resultado |
| -------- | ----------------------------------------- | ---------------------- | --------- |
| `and`    | True solo si las dos condiciones son True | `(5 > 2) and (3 < 10)` | True      |
| `or`     | True si al menos una es True              | `(5 > 8) or (3 < 10)`  | True      |
| `not`    | Invierte el valor                         | `not True`             | False     |

```python
edad = 20
es_estudiante = True
print(edad >= 18 and es_estudiante)  # True (ambas verdaderas)
print(edad < 18 or es_estudiante)    # True (segunda verdadera)
print(not es_estudiante)             # False (se invierte)
```

Ejemplo realista:

```python
edad = 17
permiso_padres = True
puede_entrar = edad >= 18 or permiso_padres
print(puede_entrar)  # True
```

## 2.4 Orden de evaluación (precedencia)

Python sigue un orden parecido al de las matemáticas:

1. Potencias (`**`)
2. Multiplicación, división, división entera, módulo (`* / // %`)
3. Sumas y restas (`+ -`)
4. Comparaciones
5. Lógicos (`not`, luego `and`, luego `or`)

Cuando tengas dudas o quieras asegurarte, usa paréntesis. Es más claro y evita errores.

```python
print(5 + 3 * 2)     # 11 (multiplica primero)
print((5 + 3) * 2)   # 16 (paréntesis primero)
```

---

## 2.5 Asignación vs Comparación

- `=` asigna: pone un valor dentro de una variable.
- `==` compara: pregunta si dos cosas son iguales.

```python
x = 5      # Asigno 5 a x
print(x == 5)  # True (pregunto si x vale 5)
```

---

## 2.6 Errores comunes

- Confundir `=` con `==`.
- Dividir por 0 (lanza error `ZeroDivisionError`).
- Creer que `/` quita decimales (usa `//` si quieres eso).
- Escribir condiciones imposibles con `and` (ej: `x > 10 and x < 5`).

## 2.8 Resumen rápido

- Aritméticos: operaciones con números.
- Comparación: preguntas que devuelven True/False.
- Lógicos: combinan respuestas.
- Paréntesis: fuerzan el orden y aclaran.

Con esto ya puedes crear condiciones útiles y expresivas en tus programas.
