# 14. Operadores de Asignación Compuesta

Atajo que combina una operación y una asignación. En vez de `x = x + 1` usamos `x += 1`.

---

## 14.1 Lista completa

| Operador | Equivalente  | Significado             |
| -------- | ------------ | ----------------------- | --- | ------------ |
| `+=`     | `x = x + y`  | Suma                    |
| `-=`     | `x = x - y`  | Resta                   |
| `*=`     | `x = x * y`  | Multiplica              |
| `/=`     | `x = x / y`  | División (float)        |
| `//=`    | `x = x // y` | División entera         |
| `%=`     | `x = x % y`  | Módulo                  |
| `**=`    | `x = x ** y` | Potencia                |
| `&=`     | `x = x & y`  | AND bit a bit           |
| `        | =`           | `x = x                  | y`  | OR bit a bit |
| `^=`     | `x = x ^ y`  | XOR bit a bit           |
| `<<=`    | `x = x << y` | Desplaza bits izquierda |
| `>>=`    | `x = x >> y` | Desplaza bits derecha   |

También para tipos compuestos (listas, sets, etc.).

---

## 14.2 Mutabilidad y efectos

Inmutables (int, float, str, tuple): crean nuevo objeto.

```python
a = 5
print(id(a))
a += 1
print(id(a))  # id cambia
```

Mutables (lista, set, dict): modifican en el lugar (in-place) normalmente.

```python
nums = [1,2]
nums += [3]
print(nums)  # [1,2,3]
```

`+=` en listas extiende; `*=` repite:

```python
nums *= 2   # [1,2,3,1,2,3]
```

---

## 14.3 Diferencia entre `+=` y `+` con reasignación

Para listas produce mismo resultado visible, pero `+=` intenta modificar la lista existente, útil si otras referencias apuntan a ella.

```python
lista = [1,2]
alias = lista
lista += [3]
print(alias)  # [1,2,3]
```

Si hubieras hecho `lista = lista + [3]` se crea una nueva lista y `alias` queda sin el cambio.

---

## 14.4 En cadenas

```python
s = "ho"
s += "la"  # crea nuevo string
```

Concatenar muchos strings en bucle así es ineficiente; mejor juntar con `"".join(lista)`.

---

## 14.5 Con diccionarios

No hay `+=` directo para fusionar, se usa `update`.
Con conjuntos (set):

```python
s = {1,2}
s |= {2,3}  # {1,2,3}
s &= {2,3}  # {2,3}
```

---

## 14.6 Bit a bit (breve)

Se aplican a la representación binaria de enteros:

```python
x = 0b1010  # 10
y = 0b0110  # 6
x &= y      # 0b0010 (2)
```

---

## 14.7 Errores comunes

- Pensar que `+=` siempre es más rápido (a veces igual en inmutables).
- Usar `+=` en bucle construyendo string gigante (usar `join`).
- Confundir `x *= 2` (duplica) con potencia `x **= 2` (eleva al cuadrado).

---

## 14.9 Resumen súper simple

- Ahorra escribir `x = x op y`.
- Inmutables crean nuevo objeto; mutables se modifican.
- Útil para acumuladores y contadores.
- Cuidado con strings en bucles (usa join).
