# 15. break y continue

Controlan el flujo dentro de bucles `for` y `while`.

---

## 15.1 break

Sale COMPLETAMENTE del bucle actual.

```python
for n in range(10):
    if n == 5:
        break
    print(n)
# Imprime 0 1 2 3 4
```

---

## 15.2 continue

Salta a la siguiente iteración (no ejecuta lo que queda abajo en esa vuelta).

```python
for n in range(6):
    if n % 2 == 0:
        continue
    print(n)
# Imprime 1 3 5
```

---

## 15.3 Usos típicos de break

- Encontrar el primer elemento que cumple algo.
- Cortar búsqueda una vez hallado (ahorra tiempo).
- Salir de un menú al elegir opción de salir.

Ejemplo búsqueda:

```python
nums = [3,8,15,2,9]
objetivo = 15
encontrado = False
for n in nums:
    if n == objetivo:
        encontrado = True
        break
print(encontrado)
```

---

## 15.4 break + else del bucle

El `else` del bucle se ejecuta SOLO si NO hubo break.

```python
for n in nums:
    if n == 100:
        break
else:
    print("No se encontró 100")
```

---

## 15.5 Usos típicos de continue

- Saltar datos inválidos y seguir.
- Ignorar espacios/líneas vacías en procesamiento de texto.

Ejemplo filtrando:

```python
valores = [10, -1, 0, 5]
positivos = []
for v in valores:
    if v <= 0:
        continue
    positivos.append(v)
```

---

## 15.6 Anidar bucles (break solo sale del interno)

```python
for i in range(3):
    for j in range(5):
        if j == 2:
            break
        print(i, j)
```

Para salir de ambos puedes usar una variable bandera:

```python
salir = False
for i in range(3):
    for j in range(5):
        if condicion():
            salir = True
            break
    if salir:
        break
```

---

## 15.7 Alternativa con funciones

Encapsular en función y usar `return` para salir de varios niveles:

```python
def buscar(nums, objetivo):
    for n in nums:
        if n == objetivo:
            return True
    return False
```

---

## 15.8 Errores comunes

- Olvidar que `continue` salta el resto del cuerpo (variables no se actualizan si estaban después).
- Usar muchos breaks que hacen difícil entender el flujo (preferir funciones o condiciones claras).
- Confundir `break` con `return` (break no devuelve valor, solo sale del bucle).

---

## 15.10 Resumen súper simple

- break: termina el bucle.
- continue: salta a la siguiente vuelta.
- `for ... else`: el else se ejecuta solo si no hubo break.
- Para salir de múltiples bucles: bandera o función.
