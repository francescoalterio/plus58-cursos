# 4. Control de Flujo: Condicionales y Bucles

El "flujo" es el camino que sigue tu programa. Con condicionales decides qué camino tomar; con bucles repites acciones.

---

## 4.1 Condicionales `if / elif / else`

Estructura básica:

```python
if condicion_principal:
    # se ejecuta si True
elif otra_condicion:
    # alternativa
else:
    # ningún caso anterior
```

Ejemplo:

```python
nota = 7.5
if nota >= 9:
    print("Sobresaliente")
elif nota >= 7:
    print("Notable")
elif nota >= 5:
    print("Aprobado")
else:
    print("Suspenso")
```

Python evalúa en orden y se queda con la primera condición verdadera.

### Comparaciones encadenadas

```python
edad = 15
if 13 <= edad <= 17:
    print("Adolescente")
```

## 4.2 Bucle `for` (recorre una secuencia)

```python
for letra in "Python":
    print(letra)
```

Recorre cada elemento uno a uno.

### Con listas:

```python
frutas = ["manzana", "pera", "uva"]
for fruta in frutas:
    print(fruta)
```

---

## 4.3 `range()` (generador de números)

```python
for i in range(3):      # 0,1,2
    print("Vuelta", i)

for i in range(2, 5):   # 2,3,4
    print(i)

for i in range(10, 0, -2):  # 10,8,6,4,2
    print(i)
```

`range(inicio, fin_excluido, paso)`.

---

## 4.4 Bucle `while` (repite mientras la condición sea True)

```python
contador = 3
while contador > 0:
    print(contador)
    contador -= 1
```

Cuidado con bucles infinitos (si la condición nunca cambia a False).

### Ejemplo de validación

```python
numero = -1
while numero < 0:
    numero = int(input("Ingresa un número positivo: "))
print("Listo", numero)
```

---

## 4.5 `break` y `continue` (control fino)

```python
for n in range(10):
    if n == 5:
        break          # sale del bucle
    if n % 2 == 0:
        continue       # salta al siguiente
    print("Impar:", n)
```

- `break`: termina el bucle.
- `continue`: salta lo que queda y sigue con siguiente vuelta.

---

## 4.6 `else` en bucles (poco conocido)

El `else` de un bucle se ejecuta si el bucle NO terminó con `break`.

```python
for n in range(3):
    print(n)
else:
    print("No hubo break")
```

```python
for n in range(3):
    if n == 1:
        break
else:
    print("No se imprime porque hubo break")
```

---

## 4.7 Bucles anidados

```python
for fila in range(2):
    for col in range(3):
        print(f"({fila},{col})")
```

---

## 4.8 Errores comunes

- Olvidar actualizar la variable en un `while` y crear un bucle infinito.
- Usar `range(len(lista))` cuando basta con `for item in lista`.
- Colocar un `else` que crees que pertenece a un `if` pero en realidad se asocia al `for`.

## 4.9 Patrones útiles

Buscar y detener al encontrar:

```python
objetivo = 42
for n in [10, 20, 42, 50]:
    if n == objetivo:
        print("Encontrado")
        break
else:
    print("No está")
```

Acumulador:

```python
suma = 0
for n in [1,2,3]:
    suma += n
print(suma)
```

Filtrado manual:

```python
pares = []
for n in range(10):
    if n % 2 == 0:
        pares.append(n)
```

## 4.11 Resumen súper simple

- `if/elif/else`: decide caminos.
- `for`: recorre colecciones.
- `while`: repite mientras algo siga siendo True.
- `break` corta, `continue` salta.
- Usa `range()` para secuencias numéricas.

Con esto controlas cómo avanza tu programa.
