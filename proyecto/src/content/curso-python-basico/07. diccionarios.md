# 7. Diccionarios

Estructura que guarda pares `clave: valor`. Claves rápidas de buscar (hash) y únicas.

---

## 7.1 Crear diccionarios

```python
vacio = {}
usuario = {"nombre": "Ana", "edad": 30}
usuario2 = dict(nombre="Luis", edad=25)
```

Claves válidas: tipos inmutables (str, int, float, tuplas sin mutables). No listas, no otros diccionarios mutables como clave.

---

## 7.2 Acceso y modificación

```python
print(usuario["nombre"])  # Error si no existe
print(usuario.get("apellido"))  # None si no existe
print(usuario.get("apellido", "(sin apellido)"))

usuario["edad"] = 31       # modifica
usuario["pais"] = "Peru"   # agrega
```

`[]` lanza KeyError si la clave falta. `get` evita error.

---

## 7.3 Eliminar

```python
usuario.pop("edad")        # devuelve el valor eliminado
usuario.pop("telefono", None)  # evita error si no existe

valor = usuario.popitem()   # quita el último par (Python 3.7+ mantiene orden)
usuario.clear()             # deja {}
```

---

## 7.4 Recorrer diccionarios

```python
for clave in usuario:
    print(clave, usuario[clave])

for clave, valor in usuario.items():
    print(clave, valor)

for clave in usuario.keys():
    ...
for valor in usuario.values():
    ...
```

`items()` da tuplas `(clave, valor)` ideal para desempaquetar.

---

## 7.5 Comprobaciones

```python
if "edad" in usuario:
    ...
len(usuario)  # cantidad de pares
```

---

## 7.6 Métodos útiles

| Método            | Uso                        | Explicación sencilla                            |
| ----------------- | -------------------------- | ----------------------------------------------- |
| get(k,def)        | d.get("x",0)               | Evita error y da valor por defecto              |
| setdefault(k,def) | d.setdefault("rol","user") | Si no existe, lo crea y devuelve el valor final |
| update({...})     | d.update(otro)             | Fusiona pares (sobrescribe claves repetidas)    |
| pop(k[,def])      | d.pop("x",None)            | Saca clave y devuelve valor                     |
| popitem()         | d.popitem()                | Saca el último par                              |
| keys()            | d.keys()                   | Vista de claves                                 |
| values()          | d.values()                 | Vista de valores                                |
| items()           | d.items()                  | Vista de pares                                  |
| clear()           | d.clear()                  | Vacía                                           |

## 7.7 Diccionarios anidados (nested)

```python
alumno = {
  "nombre": "Ana",
  "notas": {"mat": 9, "his": 8}
}
print(alumno["notas"]["mat"])  # 9
```

Actualizar profundo:

```python
alumno["notas"]["mat"] = 10
```

Evita KeyError comprobando antes o usando `setdefault`:

```python
alumno.setdefault("notas", {}).setdefault("bio", 7)
```

---

## 7.8 Comprensiones de diccionarios

Construir rápido transformando.

```python
nums = [1,2,3,4]
cuadrados = {n: n*n for n in nums}
filtrar = {n: n*n for n in nums if n%2==0}
```

Invertir claves y valores (si valores son únicos y hashables):

```python
original = {"a":1, "b":2}
invertido = {v: k for k, v in original.items()}
```

## 7.9 Conteo de frecuencias

```python
texto = "hola hola sol"
frecuencias = {}
for palabra in texto.split():
    frecuencias[palabra] = frecuencias.get(palabra, 0) + 1
```

O con `collections.Counter` (lib estándar) para conteo directo.

---

## 7.10 Evitar patrones repetidos con setdefault

```python
grupos = {}
pares = [("rojo",1),("rojo",2),("azul",3)]
for color, numero in pares:
    grupos.setdefault(color, []).append(numero)
```

Sin `setdefault` habría que comprobar si existe la lista.

---

## 7.11 Diferencia entre copiar referencias y copiar profundo

```python
import copy
orig = {"nums": [1,2,3]}
shallow = orig.copy()      # copia superficial
profundo = copy.deepcopy(orig)
shallow["nums"].append(4)
print(orig["nums"])  # [1,2,3,4] afecta a ambos
print(profundo["nums"])  # [1,2,3]
```

Usa deepcopy solo si realmente necesitas separar estructuras anidadas (es más lento).

---

## 7.12 Rendimiento (idea simple)

Búsqueda por clave en diccionario ≈ O(1) promedio (muy rápida). Listas requieren recorrer (O(n)). Por eso se usan diccionarios para accesos directos.

---

## 7.13 Errores comunes

- KeyError por usar `d["clave"]` sin comprobar.
- Sobrescribir datos al hacer `update` sin revisarlo.
- Usar lista como clave (TypeError).
- Creer que `popitem()` saca “aleatorio”: desde 3.7 saca el último insertado.

## 7.15 Resumen súper simple

- Diccionario: pares clave:valor, acceso rápido.
- Usa get / setdefault para evitar errores.
- Comprensiones crean dicts en una línea.
- Ideal para contar, agrupar y buscar rápido.
