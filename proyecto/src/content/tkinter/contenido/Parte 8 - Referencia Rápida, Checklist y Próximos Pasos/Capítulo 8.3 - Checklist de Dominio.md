# Capítulo 8.3 Checklist de Dominio

## Objetivo del capítulo

Proporcionar una lista de verificación para validar que dominas los fundamentos trabajados. Si un punto no lo puedes hacer sin mirar, repasa el capítulo pertinente.

---

## 8.3.1 Ventana y Bucle

- [ ] Crear `Tk()` y llamar a `mainloop()`
- [ ] Asignar título y tamaño inicial con `geometry`

## 8.3.2 Colocación de Widgets

- [ ] Usar `pack()` con `side`, `padx`, `pady`
- [ ] Usar `grid()` para un formulario simple
- [ ] Combinar managers en contenedores diferentes (no mezclar en el mismo)

## 8.3.3 Captura y Presentación de Datos

- [ ] Obtener texto de `Entry` y `Text`
- [ ] Mostrar resultado en un `Label` con `config()`
- [ ] Usar `StringVar` / `IntVar` para sincronizar

## 8.3.4 Interacción y Flujo

- [ ] Crear botones con callbacks
- [ ] Mostrar diálogos con `messagebox`
- [ ] Ventana secundaria con `Toplevel`
- [ ] Crear menú con `Menu`

## 8.3.5 Dinamismo

- [ ] Uso de `after()` para tarea periódica
- [ ] Manejo de eventos simples con `bind`
- [ ] Evitar `time.sleep()` en la GUI

## 8.3.6 Organización

- [ ] Estructurar en funciones
- [ ] Refactor a una clase que encapsule widgets
- [ ] Uso de helpers para reducir duplicación

---

## Micro‑Práctica

Marca los puntos y elige tres que no domines al 100%. Repite sus ejercicios hasta poder implementarlos sin mirar notas.

---

## Mini‑Resumen

Esta lista te ayuda a detectar huecos de comprensión y enfocar repasos. Completarla con soltura indica buen dominio de lo básico.
