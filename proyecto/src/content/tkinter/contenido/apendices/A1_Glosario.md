# Apéndice A.1 Glosario de Términos

## Objetivo

Definir con palabras sencillas los términos clave usados a lo largo del libro. Lectura rápida y de repaso.

---

**Aplicación (App)**: Programa que el usuario ejecuta e interactúa con él. Aquí, una ventana con controles.

**Bucle principal (mainloop)**: Ciclo interno de Tkinter que espera eventos (clics, teclas) y llama callbacks.

**Callback**: Función que se registra para ejecutarse más tarde, típicamente al pulsar un botón o suceder un evento.

**Contenedor (Frame)**: Widget que agrupa otros widgets para organizarlos juntos.

**Control / Widget**: Elemento de interfaz (botón, etiqueta, cuadro de texto) que permite mostrar información o interactuar.

**Control variable (StringVar, IntVar, etc.)**: Objeto que almacena un valor y puede vincularse a widgets para sincronizar automáticamente display y datos.

**Evento**: Suceso detectado (clic, tecla) que puede disparar una acción si se ha hecho un `bind`.

**GUI (Interfaz Gráfica de Usuario)**: Forma de interacción con ventanas, botones e íconos, en vez de sólo texto en consola.

**Layout manager**: Sistema que decide dónde y cómo se colocan los widgets (`pack`, `grid`, `place`).

**Menu**: Barra y listas desplegables con opciones de acción.

**Método**: Función asociada a un objeto (por ejemplo `widget.config(...)`).

**Refactor**: Reorganizar código para mejorar estructura sin cambiar resultado externo.

**Scrollbar**: Control para desplazarse por contenido que excede el área visible.

**Toplevel**: Ventana secundaria independiente (hija) de la principal.

**Widget**: Cualquier elemento interactivo o display en la ventana.

**yscrollcommand**: Parámetro que vincula el desplazamiento vertical de un widget (Text/Listbox) a una Scrollbar.
